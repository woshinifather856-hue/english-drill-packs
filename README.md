# EnglishDrill 内容包仓库

英语刷题助手（EnglishDrill）的在线内容包目录。

- `catalog.json`：App「内容包 → 在线目录」读取的目录文件；
- `.drillpack`：每套题一个包（题目 + 答案 + 听力 + 字幕），放在本仓库的
  **Releases（发行版）** 附件里，由 `catalog.json` 里的直链下载。

App 里填的目录地址（二选一，先确保手机能打开）：

- raw：`https://raw.githubusercontent.com/woshinifather856-hue/english-drill-packs/main/catalog.json`
- jsDelivr：`https://cdn.jsdelivr.net/gh/woshinifather856-hue/english-drill-packs@main/catalog.json`

包里只放个人学习用的材料，请勿公开传播受版权保护的内容。
