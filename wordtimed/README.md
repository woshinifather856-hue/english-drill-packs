# 全部真题与逐词听力合集

手机先更新到 EnglishDrill 3.9.9，然后在内容包页下载本合集。安装后直接打开试卷的听力题组，或从听力库打开材料。
点字幕里的词跳到该词的识别时间，长按查词；可看整篇字幕、完整播放、选段和循环。下载后无需再识别、下载模型或配置 API。

60套原有真题；22套包含听力，去重15份真实录音。音频、试题和原有答案字节保持不变，共享录音只保存一份。
字幕由本机 faster-whisper-large-v3-turbo 识别，词时间来自识别器的实际对齐结果。不是人工逐字校核，可能有错词、大小写和时间误差，可在App校对。
额外提供每份录音的 SRT 和带句时间 TXT；App 使用 words.json 中的词时间，不能用 SRT 替换后仍期待逐词定位。
